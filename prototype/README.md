# Customer Support Ticket Analysis Prototype

## Overview

This prototype implements a multi-agent customer support ticket analysis system.

## Files

- app.py
- classifier_agent.py
- sentiment_agent.py
- response_agent.py
- escalation_agent.py

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py # From PowerShell:  streamlit run app.py
```
